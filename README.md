# (11088) Bases de Datos Masivas

Repositorio git para la cursada del 2do Cuatrimestre 2026 de la Carrera de Licenciatura en Sistemas de Información de la Universidad Nacional de Luján.

## Sobre la materia

Bases de Datos Masivas aborda el ciclo completo de explotación de grandes volúmenes de
datos, desde el almacenamiento analítico hasta la extracción de conocimiento. La cursada
recorre:

- El proceso de KDD (*Knowledge Discovery in Databases*) como marco de trabajo.
- Introducción a Data Warehouse: arquitecturas, modelado dimensional y granularidad.
- Bases de datos multidimensionales, cubos OLAP y consultas analíticas.
- Procesos ETL / ELT y Data Lakes.
- Preprocesamiento de datos y análisis exploratorio (EDA).
- Machine Learning aplicado: árboles de decisión, métricas de evaluación, clustering y
  reglas de asociación.

La parte práctica se realiza sobre Python y herramientas de código abierto (JupyterLab,
motores OLAP y herramientas de integración de datos).
